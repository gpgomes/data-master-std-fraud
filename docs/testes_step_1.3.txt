4. COMPATIBILIDADE COM SCHEMAS PYDANTIC
--------------------------------------------------------------------------------

4.1 Validar transações geradas contra TransactionEvent
    Criar e rodar o seguinte script Python:

      from src.common.data_generator import DataGenerator
      from src.common.schemas import TransactionEvent
      from datetime import datetime

      gen = DataGenerator(seed=42)
      customers = gen.generate_customers(n=10)
      txs = gen.generate_transactions(customers, n=100)

      erros = 0
      for tx in txs:
          tx["timestamp"] = datetime.fromisoformat(tx["timestamp"])
          try:
              TransactionEvent(**tx)
          except Exception as e:
              print(f"ERRO: {e}")
              erros += 1

      print(f"Validados: {100 - erros}/100 — Erros: {erros}")

    Resultado esperado:
      - Validados: 100/100 — Erros: 0
